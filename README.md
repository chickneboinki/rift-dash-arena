# RIFT ARENA

A browser-based third-person build-and-shoot arena prototype built with Vite and Three.js.

## Run locally

```bash
npm install
npm run dev
```

## Current prototype features

- Responsive game menu and mode selection
- 3D arena with third-person movement and mouse aiming
- Shooting against moving bot targets
- Prototype building pieces and edit/reset controls
- Settings for sensitivity, FOV, graphics quality, edit-on-release, and performance pixel ratio

This is an early playable prototype. Online multiplayer, matchmaking, persistent accounts, cosmetics economy, and production-grade combat/build systems are not implemented yet.
